# BCM ECX Node (Beta) — 0.1.0-beta.1

Release channel: **Beta / prerelease**. Linux AMD64 only.

- Independent ECX node, enforcer, zero-fee SOLO pool and BCM dashboard.
- First-run receiving-address setup and persistent app settings.
- Pool and worker best-share history.
- Light/dark themes and responsive layout.
- Optional “Invite me to a coffee” section with ECX/BTC donation addresses.

The private image passed nine in-image checks. Local verification includes
twelve setup/package tests, six browser workflows and three destination
preflight regression groups. These are isolated tests with synthetic RPC.

Actual Umbrel installation/update, data relocation and real ASIC acceptance in
this standalone app are not yet verified. A 16 GB RAM AMD64 system and a 2 TB
SSD are recommended. The stable app ID remains `bcm-ecx` for future updates.

This document prepares prerelease notes; it does not publish an image or create
an installable catalog entry. Publication and redistribution gates remain in
[ECX-RELEASE.md](ECX-RELEASE.md).
